# Imported Roblox mesh sources

Import assets/blender/HouseDetailKit.fbx through Studio, then place the imported model in ServerStorage.DetailAssets. After verifying owner permissions and portable asset references, export the selected kit as HouseDetailKit.rbxm into this directory. Rojo reads .rbxm files here. Keep model/mesh names unchanged. See docs/BLENDER_DETAILS.md for the full workflow.
